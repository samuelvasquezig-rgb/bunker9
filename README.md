# Búnker 9

Shooter en primera persona para el navegador: sobrevive a las oleadas de drones en un búnker subterráneo. Funciona en PC y en móvil, sin instalar nada.

**Jugar:** https://samuelvasquezig-rgb.github.io/bunker9/

## Controles

| PC | Móvil |
| --- | --- |
| `WASD`: moverse | Joystick izquierdo: moverse |
| Ratón: apuntar · `← →` / `Q E`: girar | Arrastrar a la derecha: girar |
| Clic o `Espacio`: disparar | `FUEGO`: disparar |
| `P`: pausa · `M`: sonido | `⏸`: pausa |

La munición se recarga sola (+1 cada 1,2 s hasta 20). Las cajas y los botiquines que sueltan los enemigos te dan más.
